## 1. 為什麼不能把相關資料當獨立（A，Ch.8–9 開頭）

- 配對或重複測量時，兩個樣本來自同一批人，彼此**統計上相依**。把它們當獨立樣本時，比較的**估計值沒有問題，但標準誤是錯的**（§8 開頭）。
- 重複觀察通常**正相關**：同一個人的回答比不同人的回答更像（§9 開頭）。
- 正相關時，忽略相關的後果（§9.2.3）：
  - **叢集間**的效果（性別、處理組）：真正的 SE 比當成獨立時**大** → 忽略相關會高估顯著性
  - **叢集內**的效果（時間、情境）：真正的 SE 比當成獨立時**小** → 忽略相關會低估顯著性
- 這也是配對設計的好處：比較同一個人自己的兩次，估計更精確（§8.2.2）。

## 2. 邊際模型與個體模型（A，§8.2、§9.1、§10.1.4）

這是 Part 3 最核心的概念。

| | 邊際模型（marginal） | 個體模型（subject-specific） |
|---|---|---|
| 模型 | logit P(Yₜ = 1) = α + βxₜ | logit P(Yᵢₜ = 1) = αᵢ + βxₜ（或 uᵢ + α + βxₜ） |
| β 的意義 | **整體平均**（population-averaged）：一個隨機抽的人在 t = 1 的勝算，對另一個隨機抽的人在 t = 2 的勝算 | **同一個人**：固定這個人（αᵢ 或 uᵢ），兩個時間的勝算比 |
| 對應的表 | 母體平均表：把 n 個人的 2×2 部分表合併 | 個體表：每個人一張 2×2 部分表（2×2×n）（§8.2.3） |
| 配適 | GEE（Ch.9） | 條件 ML（§8.2.4*）或 GLMM（Ch.10） |

- 兩者的差別就像三因子表中**條件勝算比**與**邊際勝算比**的差別（§8.2.4，連到 §2.7）。
- **邏輯連結下，個體模型的效果通常比邊際模型大**（§10.1.4）：把每個人的 S 形曲線平均起來，得到的曲線比較平；個體差異（σ）越大，差距越大（Figure 10.1）。
- 課本 Table 8.1 例子：邊際 exp(β̂) = 1.11；個體 exp(β̂) = n₁₂/n₂₁ = 132/107 = 1.23（§8.2.2、§8.2.4、§10.1.3）。

選哪一個（§10.2.5）：

- 想**比較不同群體**（叢集間，例如男女）的整體比例 → 邊際模型較直接；個體模型要多假設整個聯合分配，較容易設錯。
- 想看**叢集內**的效果、估計每個叢集自己的值，或描述產生相關的機制 → 個體模型（GLMM）。
- 兩種都做也可以；兩者通常給出相同的實質結論（§10.2.3：GLMM 的估計值約 5–6 倍，SE 也約 5–6 倍）。

## 3. 二元配對：McNemar 檢定（A，§8.1）

設 nᵢⱼ 是第一次回答 i、第二次回答 j 的人數，π₁₂、π₂₁ 為不一致格的機率。

- **邊際同質性**：P(Y₁ = 1) = P(Y₂ = 1)。因為 P(Y₁ = 1) − P(Y₂ = 1) = π₁₂ − π₂₁，等價於 π₁₂ = π₂₁。
- H₀ 下，在 n* = n₁₂ + n₂₁ 個不一致的人中，n₁₂ ~ Bin(n*, ½)。
- **McNemar 統計量**（式 8.1）：

  z = (n₁₂ − n₂₁) / √(n₁₂ + n₂₁)，z² ~ χ²₁

- **近似條件**：n* > 10 時二項分配接近常態（§8.1.1）。本 Skill：n* ≤ 10 時改用精確二項檢定（C 級：精確檢定是二項分配的直接應用，書中未另外列出）。
- 課本不用連續性校正（太保守）（§8.1.1 的 R 輸出註解）。
- **只用到不一致的格子**：一致的 n₁₁、n₂₂ 不影響檢定。

### 3.1 相依比例差的信賴區間（A，§8.1.2）

SE = (1/n) √[(n₁₂ + n₂₁) − (n₁₂ − n₂₁)²/n]

- Wald 區間在 n* 小或比例接近 0、1 時覆蓋率太低；改善方法：每格加 0.5 再算 Wald，或用 **score 區間**（本 Skill 採用，`PropCIs::scoreci.mp`）。

### 3.2 條件勝算比（B，§8.2.4*）

- 個體模型 logit P(Yᵢₜ = 1) = αᵢ + βxᵢₜ 有 n 個 αᵢ，參數隨樣本數增加，一般 ML 會有嚴重偏誤（β̂ 趨近 2β）。
- **條件 ML** 消去 αᵢ，得 exp(β̂) = n₁₂/n₂₁。
- 用 GLMM（uᵢ 為常態隨機效果）配適時，若樣本勝算比 ≥ 1，β̂ 與條件 ML 相同（§10.1.3）。
- **配對 case-control**（§8.2.5*）：同樣的 exp(β̂) = n₁₂/n₂₁ 是 X 與 Y 的勝算比（Table 8.3：22/8 = 2.75）。

## 4. 名目配對：邊際同質性（A/B，§8.3）

c × c 方陣，**邊際同質性**：P(Y₁ = i) = P(Y₂ = i)，i = 1, …, c。

### 4.1 baseline-category logit 邊際模型（A，§8.3.1）

log[P(Y₁ = j)/P(Y₁ = c)] = αⱼ + βⱼ，log[P(Y₂ = j)/P(Y₂ = c)] = αⱼ

H₀：β₁ = ⋯ = β_{c−1} = 0，df = c − 1。用 GEE 配適，Wald 檢定（§8.3.2，`multgee::nomLORgee`）。

### 4.2 對稱與準對稱模型（B，§8.3.4*）

- **對稱**：πᵢⱼ = πⱼᵢ，即 log(πᵢⱼ/πⱼᵢ) = 0。對稱 ⇒ 邊際同質；c > 2 時反之不成立。
- 對稱模型的標準化殘差：rᵢⱼ = (nᵢⱼ − nⱼᵢ)/√(nᵢⱼ + nⱼᵢ)；c = 2 時就是 McNemar 的 z。
- **準對稱**（式 8.4）：log(πᵢⱼ/πⱼᵢ) = βᵢ − βⱼ，允許邊際不同。配適方法：把每一對 (nᵢⱼ, nⱼᵢ) 當成 nᵢⱼ + nⱼᵢ 次試驗的二項觀察值，沒有截距的 logistic 迴歸。
- 準對稱模型下，**邊際同質 ⇔ 對稱**，所以用「對稱 vs 準對稱」的 deviance 差檢定邊際同質性，df = c − 1。
- β̂ᵢ − β̂ⱼ：從 i 換到 j 的機率是從 j 換到 i 的 exp(β̂ᵢ − β̂ⱼ) 倍（§8.3.5）。

本 Skill 以 4.2 的 LR 檢定為主（只需要 `glm`，Python 也能重現），以 4.1 的 GEE Wald 檢定為對照。

### 4.3 CMH 檢定（B，§8.3.3*）

對個體表（2×c×n）做 Cochran–Mantel–Haenszel 檢定，df = c − 1；它是準對稱模型下 H₀: βᵢ = 0 的 score 檢定；c = 2 時就是 McNemar。

### 4.4 追蹤：哪一類改變了（A，§8.3.2）

把第 k 類 vs 其他合併成 2×2，套用 §8.1 的 McNemar 與比例差。

## 5. 有序配對（A/B，§8.4）

- 名目方法用 df = c − 1 偵測任何差異；**有序方法 df = 1**，偵測「整體偏高或偏低」，通常檢定力高得多，尤其 c 大、兩次回答相關很強時（§8.4）。

### 5.1 累積 logit 邊際模型（A，§8.4.1）

logit P(Y₁ ≤ j) = αⱼ + β，logit P(Y₂ ≤ j) = αⱼ

- 比例勝算：β 對每個切點相同。exp(β)：第一次落在 j 或以下（而不是 j 以上）的勝算，是第二次的幾倍。
- 用 GEE 配適；independence 局部勝算比時估計值等於把兩次當獨立的 ML，但 SE 是 robust（§8.4.2）。

### 5.2 有序準對稱模型（B，§8.4.3*）

log(πᵢⱼ/πⱼᵢ) = β(uⱼ − uᵢ)（式 8.5），u 為類別分數

- 等於截距為 0、x = uⱼ − uᵢ 的 logistic 迴歸。
- 對稱 vs 有序準對稱的 deviance 差檢定邊際同質性，df = 1。
- 分數 uᵢ = i 時：第二次比第一次高 x 類的機率，是反過來的 exp(xβ) 倍。β > 0 表示第二次（欄）的平均較高。

## 6. GEE：邊際模型的配適（A，§9.2）

### 6.1 為什麼不用 ML（§9.2）

邊際模型描述的是邊際機率，概似函數卻需要聯合分配；類別資料沒有像多元常態那樣簡單的聯合分配，ML 很困難。

### 6.2 準概似（§9.2.1）

GLM 的概似方程式只用到「var(Y) 怎麼依賴 μ」。準概似只指定這個關係（不指定完整分配），可以處理相關造成的過度離散：var = φ·Tπ(1−π)，φ > 1 為過度離散。

### 6.3 GEE 的步驟（§9.2.2）

1. 指定邊際模型：連結函數與線性預測式
2. 指定 var(Yₜ) 與 E(Yₜ) 的關係（例如二項）
3. 猜一個 **working correlation**
4. 解廣義估計方程式得到估計值
5. 用資料實際的變異與共變，把 SE 調整成 **robust（sandwich）SE**：即使 working correlation 猜錯也有效

working correlation（§9.2.2）：

| 結構 | 形式 | 課本建議 |
|---|---|---|
| exchangeable | corr(Yₛ, Yₜ) = ρ 對所有配對相同 | **沒有特別理由時用這個** |
| autoregressive | corr(Yₛ, Yₜ) = ρ^{|t−s|} | 時間序列 |
| independence | 0 | 估計值等於當獨立的 ML |
| unstructured | 每對各自估計 | 參數多，T 大時不建議 |

多類別 GEE（`multgee`）用**局部勝算比**描述相關，比相關係數更適合類別資料（§9.3.2）。

### 6.4 GEE 的限制（§9.2.4）

- 沒有概似函數 → **沒有 deviance，不能做 LR 檢定、不能比較 deviance 檢查配適**；推論用 robust SE 的 Wald 檢定。
- robust SE 是**大樣本**方法；樣本小時傾向低估真正的 SE。課本沒有給樣本數門檻。
- 缺失資料：GEE 需要缺失**完全隨機**（MCAR）才有效（§9.5.1）。

### 6.5 課本例子（§9.2.3）

Table 9.1，logit P(Yₜ = 1) = α + βₜ + γx（情境 3 為參考）：

| | 當獨立（glm） | GEE independence robust | GEE exchangeable robust |
|---|---|---|---|
| sit1 | 0.149 (0.066) | 0.149 (0.030) | 0.149 (0.030) |
| gender | 0.004 (0.054) | 0.004 (0.088) | 0.003 (0.088) |

情境（叢集內）的 SE 變小、性別（叢集間）的 SE 變大，和第 1 節的說明一致；ρ̂ = 0.817。

## 7. GLMM：隨機效果模型（A，§10.1–10.2）

### 7.1 模型（§10.1.1）

g(μᵢₜ) = uᵢ + α + β₁xᵢₜ₁ + ⋯ + βₚxᵢₜₚ，uᵢ ~ N(0, σ²) 獨立

- uᵢ 是**隨機效果**（random effect），σ² 是**變異成分**（variance component）。
- 為什麼不把 uᵢ 當固定參數：叢集是母體的一組樣本，要推論到所有叢集；而且叢集很多時參數太多。當隨機效果只多 1 個參數 σ²。
- 給定 uᵢ，同一叢集的觀察值獨立；對 uᵢ 平均後，模型隱含叢集內的**非負相關**。σ 越大，相關越強（§10.1.2）。
- logit 連結＋常態隨機效果 = **logistic-normal 模型**。

### 7.2 配適（§10.1.5）

- 概似函數要對 uᵢ 的常態分配積分，沒有封閉解，用數值方法。
- **Gauss–Hermite quadrature**：用有限項的和近似積分；點數 q 越多越準。軟體預設常很小（例如 5），**要增加 q 確認估計值與 SE 已經穩定**；adaptive quadrature 更有效率。
- 只有隨機截距（或加一個隨機斜率）時 quadrature 可行；更複雜時用 Laplace 近似、Monte Carlo 或貝氏方法。
- 本 Skill 的驗證：課本墮胎例（σ̂ = 8.75）25 點時 σ̂ = 9.34，100 點才和課本一致（C 級：本 Skill 實測）。

### 7.3 推論（§10.1.6）

- 固定效果：一般的 Wald 或 LR 檢定。
- 隨機效果的預測值 ûᵢ：給定資料時 uᵢ 條件分配的平均；用到所有叢集的資料。
- **檢定 σ = 0**：σ 不能為負，H₀ 在參數空間的**邊界**，一般檢定不適用（σ̂/SE 不是近似常態）。LR 統計量的分配：½ 機率為 0、½ 為 χ²₁。所以 **P 值 = χ²₁ 右尾機率的一半**。
  - 罰球例（§10.2.2）：LR = 1.56，χ²₁ 右尾 0.21，P ≈ 0.11。（課本原文「P 值是右尾機率的一半，右尾機率為 0.21」，容易誤讀成 P = 0.21。）

### 7.4 小區域估計與縮減（§10.2.1）

logit(πᵢ) = uᵢ + α：每個區域（或球員）的估計是自己的樣本比例與整體比例的加權平均。樣本越少、σ̂ 越小，**往整體比例縮得越多**。罰球例：樣本比例 0.33–1.00，模型估計 0.66–0.81，和球季結束時的真實比例更接近（§10.2.2）。

### 7.5 課本例子（§10.2.3，Table 10.3）

| 效果 | GLMM | GEE（exchangeable） |
|---|---|---|
| β₁ − β₃ | 0.835 (0.160) | 0.149 (0.030) |
| β₁ − β₂ | 0.542 (0.157) | 0.097 (0.028) |
| β₂ − β₃ | 0.292 (0.157) | 0.052 (0.027) |
| γ（性別） | 0.013 (0.490) | 0.003 (0.088) |
| σ | 8.75 | — |

1850 人中 1595 人三種情境的回答都相同 → 個體差異極大（σ̂ = 8.75）→ GLMM 的效果約為 GEE 的 5–6 倍，SE 也一樣，結論相同。

### 7.6 Rasch 模型（A，§10.2.4，延伸說明用）

logit P(Yᵢₜ = 1) = uᵢ + α + βₜ：uᵢ 是受試者 i 的能力、βₜ 是題目 t 的容易程度（item response model）。

## 8. 範圍外但相關的方法（說明用）

| 方法 | 重點 | 節 |
|---|---|---|
| 轉移模型 | 把前一次結果 yₜ₋₁ 當解釋變數；給定前一次後各次獨立，可以用一般 GLM 配適；效果是「給定前一次」的條件效果，通常比邊際模型弱 | §9.4 |
| 以初始回答為共變數 | 配對資料時，把 Y₂ 當結果、y₁ 當解釋變數，比較組別差異（例如失眠例 β̂ = 0.885） | §9.4.3 |
| 缺失資料 | MCAR：缺不缺和任何變數無關；MAR：只和已觀察到的變數有關。ML（含 GLMM）在 MAR 下有效，GEE 需要 MCAR；多重插補 | §9.5* |
| 有序 GLMM | 累積 logit 加隨機截距；軟體的參數化可能和課本正負號相反 | §10.3.1 |
| 多層模型 | 學生在學校內，學生層與學校層各有隨機效果 | §10.4 |
| 評分者一致性 | 一致 ≠ 關聯；Kappa 受邊際分配影響很大 | §8.5* |
