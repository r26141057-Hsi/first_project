# 分析報告：學生平日和週末的喝酒程度一樣嗎？

- 資料檔：`student_por.csv`
- 方法：Cumulative logit marginal model for ordinal matched pairs（Agresti §8.4）
- 資料結構：paired
- 選擇理由：同一位學生平日（Dalc）與週末（Walc）的有序回答（1 < 2 < 3 < 4 < 5），只比較兩次的邊際分布；有序方法 df = 1、檢定力較高（§8.4）

## 結論與解釋

### 1. 一句話結論

不一樣。有證據顯示，學生週末的喝酒程度整體比平日高（累積 logit 邊際模型，Wald z² = 322.04，df = 1，P < 0.001）。

### 2. 效果的大小與方向

- **整體來說（邊際模型，§8.4.1）**：週末（Walc）落在較高喝酒等級的勝算是平日（Dalc）的 **3.939 倍**（95% 信賴區間 3.391 到 4.575）。反過來說，平日落在較高等級的勝算是週末的 0.254 倍（0.219 到 0.295）。β̂ = 1.371，robust SE = 0.076。這裡比的是全體學生平日和週末兩個分布，屬於整體層次的比較，不是在說每一位學生自己的變化。
- **這是勝算的倍數，不是機率的倍數。** 比例勝算模型假設不論切在哪個等級（≤1、≤2、≤3、≤4），這個倍數都一樣。
- **兩次的分布**：平日回答「1」的有 69.5%，週末只有 38.1%；回答 4 或 5 的，平日各占 2.6%，週末分別是 13.4% 和 6.9%。平均分數是平日 1.50、週末 2.28（分數 1–5）。平均分數只用來幫助描述方向。
- **逐人來看**：週末比平日高的有 332 人（51.2%），比平日低的有 13 人（2.0%），兩次一樣的有 304 人（46.8%）。
- **對照方法**：有序準對稱模型 β̂ = 2.192，和對稱模型比較 LR = 338.71（df = 1），P < 0.001，結論方向相同（§8.4.3）。

### 3. 注意事項

- 這次分析沒有任何警告。649 人都沒有缺失，兩次的類別相同（1–5），也沒有空的類別配對。
- **比例勝算假設（§8.4.1）**：模型假設每個切點的效果相同，這次沒有做正式檢定。從逐人比較和邊際分布來看，週末偏高的方向很一致，但在不同切點，倍數的大小可能不完全一樣。
- 這是觀察性資料，又是學生自己回答的結果，只能說「週末的喝酒程度比較高」，不能推論是什麼原因造成的。

### 4. 限制與下一步

- 如果想知道哪些學生的平日和週末差距比較大（例如和性別、外出頻率 goout 有沒有關係），可以把資料轉成長格式（每人 2 列），用有序 GEE（`gee_ordinal`，§9.3）加入解釋變數。
- 如果想看每個等級各自變了多少，可以補做名目的邊際同質性檢定（`paired_nominal`，§8.3）當作描述，但它沒有用到順序資訊。

## 結果

- 共 649 人，每人兩次測量（Dalc、Walc），類別：1、2、3、4、5。
- 累積 logit 邊際模型（GEE）：β̂ = 1.371（robust SE 0.076），Wald z = 17.95，P < 0.001。
- Dalc 落在較高類別的勝算是 Walc 的 0.254 倍（95% 信賴區間 0.219 到 0.295）；反過來，Walc 落在較高類別的勝算是 Dalc 的 3.939 倍（3.391 到 4.575）。對每個切點都相同（比例勝算）。
- 方向：Dalc 傾向落在較低的類別（較接近「1」）。
- 逐人比較：Walc 比 Dalc 高的有 332 人（51.2%），較低的 13 人（2.0%），相同的 304 人（46.8%）。
- 對照：有序準對稱模型 β̂ = 2.192，和對稱模型比較 LR = 338.71（df = 1），P < 0.001；平均分數 Dalc = 1.50、Walc = 2.28（分數 1, 2, 3, 4, 5）。
