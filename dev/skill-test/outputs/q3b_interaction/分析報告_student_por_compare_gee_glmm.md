# 分析報告：三次考試的及格率有變化嗎？和性別有關嗎？

## 結論與解釋（加入 period × sex 交互作用）

### 一句話結論

證據不足，無法確定男女的及格率隨考試次數的變化是否不同；交互作用的檢定兩個模型都不顯著，所以沒有交互作用的模型（`output/分析報告_student_por_compare_gee_glmm.md`）已足以描述資料。

### 交互作用的檢定

- GEE：robust Wald = 0.32（df = 2），P = 0.853。
- GLMM：LR = 0.49（df = 2），P = 0.783。

交互作用的勝算比（男生相對於女生，「第 k 次 vs 第 1 次」勝算比的倍數）：

| 項目 | 整體來說（GEE） | 對同一位學生（GLMM） |
|---|---|---|
| period2:sexM | 0.913（95% CI 0.660 到 1.263），P = 0.582 | 0.738（95% CI 0.300 到 1.820），P = 0.510 |
| period3:sexM | 0.967（95% CI 0.685 到 1.366），P = 0.851 | 0.773（95% CI 0.284 到 2.102），P = 0.614 |

- 四個信賴區間都包含 1，但都相當寬，尤其是 GLMM 的區間（0.284 到 2.102）。所以不能說「男女的變化完全一樣」，只能說這份資料沒有足夠證據顯示兩者不同。

### 加入交互作用後主效果的意思改變了

有了交互作用之後，主效果代表的是**特定組別**的比較：

- **period2、period3**：代表**女生**（參考組）的第 k 次 vs 第 1 次。例如整體來說，女生第 3 次及格的勝算是第 1 次的 1.786 倍（95% CI 1.427 到 2.236）；對同一位女生，是 6.045 倍（95% CI 2.882 到 12.678）。
- **sexM**：代表**第 1 次考試**的男生 vs 女生。整體來說，女生及格的勝算是男生的 1.491 倍（95% CI 1.039 到 2.141）；對同一位學生，是 3.631 倍（95% CI 1.191 到 11.072）。

### 注意事項

- GLMM 的「Likelihood-ratio: period」（df = 4）和「Likelihood-ratio: sex」（df = 3）是把該變數的主效果**連同交互作用**一起移除後的檢定，和 GEE 的 Wald 檢定（df = 2、df = 1，只檢定主效果）不是同一個假設，不能直接比較。
- **QUADRATURE_UNSTABLE**（§10.1.5）：用 50 點和 100 點配適的估計值差異超過 0.0005（σ̂：4.842 vs 4.857），已採用點數較多（100 點）的結果。
- **ALL_SAME_RESPONSE**（§10.1.4、§10.2.3）：81.8% 的學生三次結果都相同，σ̂ = 4.857。GLMM 的效果與 SE 都比 GEE 大，這是兩個模型回答不同的問題，不是錯誤。period3:sexM 的 GLMM／GEE 比值是 7.77，因為兩者的估計值都很接近 0，比值不穩定，不需要特別解讀。
- GEE 的 SE 都是 robust SE；本資料有 649 個叢集（§9.2.4）。
- 及格是以 10 分為門檻切出來的，會損失分數本身的資訊。

### 限制與下一步

- 因為交互作用不顯著，建議以沒有交互作用的模型作為主要結論：第 3 次的及格率比第 1 次高，女生的及格率比男生高。

- 資料檔：`student_por.csv`
- 方法：GEE (population-averaged) vs GLMM (subject-specific)（Agresti §10.1.4, §10.2.5）
- 資料結構：repeated
- 選擇理由：同上一個分析，另加入 period:sex 交互作用，看男女的及格率變化是否不同（使用者要求；§9.2、§10.2）

## 結果

- 資料沒有 id 欄，依列號產生 id（1–649），每一列視為一個叢集。
- 把 G1、G2、G3 轉成長格式：G 欄為測量值，period 欄為時間（1 = G1、2 = G2、3 = G3），共 1947 列。
- 新變數 passed 由 G 轉換：< 10 → fail；≥ 10 → pass。
- 提醒：把連續的 G 切成類別會損失資訊，結論可能隨切點改變。
- 同一份資料（649 個叢集、1947 筆）分別配適 GEE（整體平均）與 GLMM（同一個叢集）。
- period2：GEE 估計 0.147（SE 0.102）、GLMM 估計 0.464（SE 0.324），GLMM / GEE = 3.16。
- period3：GEE 估計 0.580（SE 0.115）、GLMM 估計 1.799（SE 0.378），GLMM / GEE = 3.10。
- sexM：GEE 估計 -0.400（SE 0.185）、GLMM 估計 -1.290（SE 0.569），GLMM / GEE = 3.23。
- period2:sexM：GEE 估計 -0.091（SE 0.166）、GLMM 估計 -0.303（SE 0.460），GLMM / GEE = 3.33。
- period3:sexM：GEE 估計 -0.033（SE 0.176）、GLMM 估計 -0.258（SE 0.511），GLMM / GEE = 7.77。
- GLMM 的隨機效果標準差 σ̂ = 4.857；GEE 的 working correlation 估計 = 0.651。
- 兩者回答不同的問題：GEE 是母體中隨機抽的人的平均效果，GLMM 是固定同一個叢集時的效果；邏輯連結下，σ 越大，整體平均的效果越接近 0（§10.1.4）。

## 注意事項

- **QUADRATURE_UNSTABLE**：用 50 點和 100 點配適的估計值差異超過 0.0005（σ̂：4.842 vs 4.857），數值積分可能還沒穩定；以下報告 100 點的結果。（Agresti §10.1.5）
- **ALL_SAME_RESPONSE**：有 81.8% 的叢集所有回答都相同，σ̂ = 4.857：叢集之間差異越大，GLMM（同一個叢集）的效果就比 GEE（整體平均）大越多，SE 也一樣變大。這不是錯誤。（Agresti §10.1.4、§10.2.3）
