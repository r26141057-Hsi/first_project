# 分析報告：三次考試的及格率有變化嗎？和性別有關嗎？

## 結論與解釋

### 一句話結論

整體來說，有證據顯示三次考試的及格率有變化，主要是第 3 次（期末）比第 1 次高；也有證據顯示及格與性別有關，女生的及格勝算比男生高。

### 效果的大小與方向（整體平均效果，GEE，robust SE）

- **時間**：控制性別後，三次考試及格勝算都相同的 H₀ 被拒絕（robust Wald = 47.85，df = 2，P < 0.001）。
  - 第 2 次 vs 第 1 次：整體來說，第 2 次及格的勝算是第 1 次的 1.110 倍（95% CI 0.946 到 1.303，P = 0.200）。證據不足，無法確定第 2 次和第 1 次的及格勝算不同；信賴區間從略低於 1 到約 1.3 倍。
  - 第 3 次 vs 第 1 次：整體來說，第 3 次及格的勝算是第 1 次的 1.759 倍（95% CI 1.482 到 2.089，P < 0.001）。
  - 描述上，三次的及格比例依序為 0.7581、0.7766、0.8459。
  - 第 3 次 vs 第 2 次的直接比較，這次的輸出沒有提供。
- **性別**：控制考試次數後，整體來說，男生及格的勝算是女生的 0.644 倍（95% CI 0.464 到 0.894，P = 0.009）；換個方向說，女生及格的勝算是男生的 1.554 倍（95% CI 1.119 到 2.157）。各次考試女生的及格比例都比男生高（例如第 1 次 0.7885 vs 0.7143）。
- 這些是「整體來說」的效果（母體中女生與男生、第 3 次與第 1 次的及格比例比較），不是「同一位學生」的效果；勝算比也不是機率的倍數。

### 注意事項

- 本次分析沒有出現警告代碼。649 位學生每人都有 3 筆完整資料，沒有缺失。
- 叢集數：GEE 的 robust SE 是大樣本方法，叢集少時傾向低估（§9.2.4）。本資料有 649 個叢集，課本沒有給門檻，請自行判斷是否足夠。
- working correlation 用 exchangeable，估計相關 0.651。即使這個結構設錯，robust SE 仍然有效（§9.2.2）。
- GEE 沒有概似函數，所以檢定用 robust Wald，不用概似比檢定（§9.2.4）。
- 及格是由 0–20 分以 10 分切出來的，會損失分數的資訊，結論可能隨切點改變。
- 成績 0 分可能代表缺考或退學，目前照原始數字算成不及格，可能影響第 3 次的比例。
- 這是觀察性資料，只能說「有關聯」「比較高」，不能說性別「造成」及格與否。
- 模型沒有放時間 × 性別交互作用，所以假設男女的及格勝算隨時間變化的倍數相同。

### 限制與下一步

- 想知道「對同一位學生」的變化，可以再配隨機截距 GLMM（`glmm_binary`）。因為 81.8% 的學生三次結果都相同，GLMM 的勝算比預期會比 GEE 大；兩者回答的是不同的問題（§10.1.4）。
- 可以加入 `period:sex` 交互作用，檢查男女的變化趨勢是否不同。
- 可以排除 0 分（可能是缺考）或改用其他及格線，做敏感度分析。

- 資料檔：`student_por.csv`
- 方法：Marginal logistic model fitted by GEE（Agresti §9.2）
- 資料結構：repeated
- 選擇理由：同一位學生三次考試的二元結果（G ≥ 10 為及格）；使用者只想知道整體來說及格率有沒有變、男女整體有沒有差，所以用邊際 logistic GEE（§9.2）
- 效果的意義：整體平均（population-averaged）

## 結果

- 資料沒有 id 欄，依列號產生 id（1–649），每一列視為一個叢集。
- 把 G1、G2、G3 轉成長格式：G 欄為測量值，period 欄為時間（1 = G1、2 = G2、3 = G3），共 1947 列。
- 新變數 passed 由 G 轉換：< 10 → fail；≥ 10 → pass。
- 提醒：把連續的 G 切成類別會損失資訊，結論可能隨切點改變。
- 共 649 個叢集、1947 筆觀察值；每個叢集的筆數：3 筆 649 個。
- 叢集間變數（同一個叢集內不變）：sex；叢集內變數（同一個叢集內會變）：period。
- 邊際 logistic 模型（GEE），成功 =「pass」，working correlation = exchangeable（估計相關 0.651）。
- period2：整體來說，勝算比 = 1.110（95% 信賴區間 0.946 到 1.303），P = 0.200。
- period3：整體來說，勝算比 = 1.759（95% 信賴區間 1.482 到 2.089），P < 0.001。
- sexM：整體來說，勝算比 = 0.644（95% 信賴區間 0.464 到 0.894），P = 0.009。
- Wald (robust SE): period = 47.85（df = 2），P < 0.001。
- Wald (robust SE): sex = 6.92（df = 1），P = 0.009。
