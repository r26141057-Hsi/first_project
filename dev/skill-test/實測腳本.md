# Part 3 skill 實測腳本

## 步驟

1. **先填 `judgment.yml`**（依課本自己判斷，Claude 不可代填）。
2. 每一題開一個**全新的對話**，工作資料夾設為 `Desktop\claude\Part3-實測\q1`（q2、q3、q4 依此類推）。每個資料夾只有 `student_por.csv` 和 skill（`.claude\skills\categorical-correlated`），看不到答案。
3. 貼上「開場訊息」。skill 停下來問問題時，照「確認時回答」回覆；表格沒寫到的問題，依你自己對資料的理解回答，並記下來。
4. Claude 要執行 `Rscript` 時會請你允許，按允許即可。
5. 每一題結束後記錄：
   - 截圖：確認清單、✅／⚠️／❌ 判斷、最後的解釋
   - 對話紀錄（匯出或複製成 `transcript_q1.md`）
   - skill 產生的 `result.json`、`分析報告_*.md`、圖
6. 全部做完後，把 skill 的判斷和 `judgment.yml` 並排、數字和 `verify_results.json` 對照（交給 Claude 整理）。
